GitHub 仓库

令牌只保存在本浏览器（localStorage），不会写进网页，也不会提交到仓库。

如何创建令牌

  1. GitHub → Settings → Developer settings
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. Repository access 选 Only select repositories，勾选你的博客仓库
  4. Permissions → Repository permissions → Contents: Read and write
  5. 生成后复制到这里保存，再点「测试连接」

危险操作

1. 先改登录口令

在站点目录运行下面的命令，把输出替换到 js/admin-config.js 的 PASSWORD_HASH：

node tools/hash-password.js 你的新口令

2. 连接你的仓库

到「发布设置」填好用户名、仓库名、分支和令牌，保存后点「测试连接」。看到成功后，之后所有修改都会自动提交。

3. 写文章

文章管理 → 新建文章 → 填标题和正文（Markdown）→ 保存并发布。文章列表、时间轴、分类、标签、搜索都会自动更新。

4. 说说 / 相册 / 友链

左侧菜单分别管理。每一条都可以编辑和删除，改动同样是一次 Git 提交。

5. 图片怎么放

把图片上传到仓库的 assets/ 目录，然后在正文里写 ![说明](assets/图片名.jpg)，或在「封面图地址」里填路径。

6. 本地预览

直接双击 HTML 会被浏览器拦截数据读取，请在站点目录运行：

node tools/serve.js
